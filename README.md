# Lenny Growth Assistant

AI-powered conversational assistant for product and growth teams, grounded in Lenny Podcast transcripts.

## Project Status

Early development.

## Core Capabilities

- Grounded product and growth Q&A
- Transcript-based retrieval and source tracing
- Independent chat sessions with PostgreSQL persistence
- Local Ollama model support
- Cloud LLM support
- Ship30-style content generation
- Markdown and HTML/CSS artifact generation
- Native artifact viewing
- Structured errors, health checks, logging, and automated tests
